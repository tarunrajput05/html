# Five Page HTML Website

## 📌 Project Overview

This project is a simple multi-page website developed using **HTML** as part of an academic assignment.

The website contains five different pages, and each page has the same navigation menu at the top. Users can easily navigate between all five pages using the navigation links.

## 📄 Pages Included

1. **Home** – `index.html`
2. **About Us** – `aboutus.html`
3. **Services** – `services.html`
4. **FAQ** – `faq.html`
5. **Gallery** – `gallery.html`

## 🛠️ Technologies Used

- HTML5
- Visual Studio Code
- Git
- GitHub

## ✨ Features

- Five separate HTML pages
- Common navigation menu on every page
- Easy navigation between all pages
- FAQ section
- Services section
- Gallery section
- Simple and user-friendly structure

## 📁 Project Structure

```text
five-pages-assignment/

├── services.html
├── faq.html
├── gallery.html
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it using **Live Server** or open the HTML file directly in a web browser.
5. Use the navigation links to visit all five pages.
